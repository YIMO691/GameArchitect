Lesson 063: automated performance testing

    Lesson 066 · Challenge: predict first, then tap Set up and check

      What this shows

      Remove noise at the source

      A dedicated machine, a fixed path with a fixed seed and a warm-up each remove a cause of noise. Statistics can't do that for you.

      Compare against a baseline, not one build

      The last build is just one noisy number. A median of several runs, compared with the last 10 builds, is steady enough to trust.

      Statistics can hide a regression

      On a noisy test, a threshold of 3 × noise is so wide that a real 0.4 ms regression fits inside it. Make the test quiet first.

      This lab is a model, not a measurement. Every run's result is 14.3 ms (14.7 from build 14) plus noise: shared agent ±0.6 ms and a 15% chance of a +2 ms spike from another job; dedicated ±0.12. Free play ±0.5, fixed path ±0.08. Without warm-up, loading and shader compiling add 0–2 ms that change from run to run. A run takes 2.5 minutes (2.7 with warm-up). The noise is random but fixed, so every setting always shows the same builds.
