    What this shows
    
    
    
      
    Components fix design, not speed
    The Gull became a prefab with no new class, but 11,000 engine calls and hops to the Transform made the step slower: 2.75 ms.
    
      
    ECS: columns and systems
    Each system reads a few packed arrays from start to end. No jumps, no per-critter call, nothing unused loaded: 10 ns per visit.
    
      
    ECS has its own bill
    Adding or removing a component moves the entity to another table. 1,600 tag changes cost 0.80 ms; a bool field costs almost nothing.
    
    
    
    
    This lab is a simulation, not a measurement. Costs per update come from Lesson 012's phone numbers (approximate): fat base class 190 ns, component update 250 ns, ECS visit 10 ns, structural change 0.5 µs. The mix is always 40% fish, 30% birds, 20% crabs, 10% gulls. The memory view is a sketch: it is slowed down a lot, and array lengths are not to scale. Real engines differ in the details, not in the shape.
