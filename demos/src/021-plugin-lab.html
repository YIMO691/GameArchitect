Lesson 021: plugins and extension points

      
    
    
    
  
    

  
    
    
    What this shows
    
    
    
      
    Seams become sockets
    Leo's 23 checks were 5 kinds of change. Five sockets in the core replace all 49 checks of three modes. A new mode is a new folder, not an edit to ScoreSystem.cs.
    
      
    The core owns registration
    Moving code into a plugin did not fix the ×2 bug: a hand-written undo still forgot 3 of 11 pieces. A scope the core closes forgets nothing.
    
      
    Order and versions are promises
    Arrival order gave the same fish 90 or 85. Phases make it 90 for everyone. A version check turns an old mod's crash into one refused line in the log.
    
    
    
    
    This lab is a simulation, not a measurement. It uses the lesson's numbers: 23, 11 and 15 checks per mode, a reflection scan of about 380 ms and 2.1 MB on a mid-range phone, about 1 ms per plugin from a baked list, 11 Tournament pieces, and a parrotfish worth 40. A real engine's times depend on the device and the number of types; the bugs are the same.
