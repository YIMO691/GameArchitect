Lesson 057: memory budgets per platform

    Lesson 066 · Challenge: predict first, then tap Set up and check

      What this shows

      The device's RAM is not your budget

      The system, other apps and the graphics driver take their share first. A 2 GB phone lets the game use about 1.3 GB before it's killed.

      Budget the peak

      The steady state may fit while a scene change briefly holds two scenes. Plan transitions so the peak fits too.

      Budgets per system, per device

      Each system owns a number on each device class, and CI checks it. New content then fits by rule, not by luck.

      This lab is a simulation, not a measurement. It uses Lesson 057's numbers: limits before the system kills or refuses the game: 1,300 MB on the 2 GB Android phone, 1,900 MB on the 4 GB iPhone, 3,200 MB on the handheld; full-quality steady state 1,730 MB plus render targets (120 / 140 / 53 MB native, 53 / 101 / 53 MB scaled); scene changes add 300 MB when overlapping, 60 MB with a transition scene; texture tiers 225 / 600 / 900 MB and meshes 120 / 180 / 180 MB; 2.1's 150 MB of textures become 38 / 100 / 150 MB when tiered.
