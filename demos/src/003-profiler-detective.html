    What this shows

    The average hides spikes

    Five 66 ms frames out of 300 barely move the average. P99, the worst frame and the count over budget show what players feel.

    Self time and calls find the worker

    Sorted by total, a manager function sits on top. Sorted by self, FindPath and its 5,000 calls stand out. Comparing with a normal frame shows the one row that changed.

    Measure where it counts

    The editor with Deep Profile gets the shape roughly right but the sizes wrong, and even flips the normal frame to CPU-bound. Decide and prove on the target build.

    This lab is a simulation, not a measurement. It uses Lesson 003's numbers: other CPU work 12 ms, GPU 14.5 ms every frame, one path costs 10.8 µs, each zombie re-plans every 60 frames. "Editor + Deep Profile" is modelled as 2× on normal CPU work and 3× on FindPath; real overhead varies a lot by project. Real recordings are noisier: frames wobble by a few tenths of a millisecond.
